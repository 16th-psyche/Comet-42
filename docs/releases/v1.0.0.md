**Comet 42 is a free, open-source AI assistant that lives in your Mac's menu bar.** Select text,
paste content or copy a screenshot, press <kbd>⌥</kbd> <kbd>Space</kbd>, and ask a question or
run a preset like *Improve Writing* or *Change to Email*. **Replace** puts the result straight back
where it came from. It runs on the Claude Code or Codex CLI you already use, so there are no API
keys.

This is the first public release.

## ✨ Highlights

- **Works in any app.** It reads your selection through macOS Accessibility, and falls back to a
  temporary copy for apps that don't expose it.
- **Screenshots, files and pasted text.** A screenshot copied in the last two minutes is attached
  automatically. <kbd>⌘</kbd> <kbd>V</kbd> or drag-and-drop adds images, PDFs and text or code
  files.
- **12 built-in presets on <kbd>⌘1</kbd>–<kbd>⌘9</kbd>:**
  - Improve Writing; Fix Spelling and Grammar (with highlighted changes).
  - Explain This in Simple Terms.
  - Change Tone to Professional; Change Tone to Friendly; Change to Email; Make Concise.
  - Format as Bullets; Format as Table.
  - Summarize; Extract Text; Translate to English.

  Edit, reorder or add your own in Settings.
- **Replace or copy.** <kbd>⌘</kbd> <kbd>↩</kbd> pastes the answer over your original selection
  and puts your clipboard back. If the app can't take it, the answer is copied instead.
- **Chat with follow-ups.** Answers stream in as Markdown with code blocks and tables.
- **Your choice of model.** Any model your Claude CLI offers (Opus, Sonnet, Haiku…) or the Codex
  CLI. You can set one model for questions and another per preset.
- **Accessible and adjustable.** The panel moves and resizes and remembers where you left it, text
  scales from 85% to 160%, VoiceOver labels every control, and Reduce Transparency and Increase
  Contrast are supported.
- **Universal.** Runs natively on Apple silicon and Intel Macs.

## 📋 Requirements

- **macOS 26** or later.
- At least one AI CLI, installed and signed in:
  - **Claude Code:** `curl -fsSL https://claude.ai/install.sh | bash`, then `claude auth login`
  - **Codex CLI:** `npm i -g @openai/codex`, then `codex login`

## 📦 Install

1. Download **`Comet-42-1.0.0-macOS-universal.dmg`** below, open it, and drag **Comet 42** into
   **Applications**.
2. **Open it the first time** (see the note below).
3. When asked, turn on **Comet 42** in **System Settings → Privacy & Security → Accessibility**.
4. Click the comet in the menu bar, then **Settings → AI Tools**, and check your CLI shows
   **Ready**.

> [!IMPORTANT]
> **First launch: Comet 42 isn't notarized by Apple yet,** so the first time you open it, macOS
> warns that it can't verify the app and won't open it. To open it:
>
> 1. Open Comet 42 once and dismiss the warning.
> 2. Go to **System Settings → Privacy & Security**, scroll down, and click **Open Anyway** next to
>    Comet 42.
>
> Or, in Terminal: `xattr -dr com.apple.quarantine "/Applications/Comet 42.app"`
>
> The full source is in this repository if you'd rather build it yourself.

## ⌨️ Quick reference

| Shortcut | Action |
| --- | --- |
| <kbd>⌥</kbd> <kbd>Space</kbd> | Open Comet 42 (change it in Settings) |
| <kbd>↩</kbd> | Ask |
| <kbd>⌘</kbd> <kbd>1</kbd>–<kbd>9</kbd> | Run a preset |
| <kbd>⌘</kbd> <kbd>V</kbd> | Paste text, a screenshot or a file |
| <kbd>⌘</kbd> <kbd>↩</kbd> | Replace the selection with the answer |
| <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>C</kbd> | Copy the last answer |

## ⚠️ Known limitations

- **Not notarized** (see above).
- **Hotkey clashes.** If another app already uses <kbd>⌥</kbd> <kbd>Space</kbd>, both will respond.
  Pick a different shortcut in **Settings → General**.
- **Codex answers arrive in larger chunks** than Claude's, rather than word by word.
- **Conversations aren't saved** after the panel's chat is reset or the app quits.

## 🔒 Privacy

Comet 42 stores no API keys and has no account. Requests go through your own Claude or Codex CLI,
under that provider's terms. Nothing is read until you press the shortcut, and the clipboard is
restored after Comet 42 borrows it.
